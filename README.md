For your first small task, set yourself a one-line question: 
“Which airlines had the worst average departure delays, and does it depend on the age of the plane?” 
That forces you to join flights to planes and airlines, 
which is the same motion as linking person-level and event-level tables.

Habit to build now:
At the end of each session: render the .qmd, commit with a specific message 
(“week 1: joined flights to planes, computed delays by airline”), and push. 
That gives you a dated progress log with no extra effort.
